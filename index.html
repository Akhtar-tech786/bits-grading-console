Marks file format guidance

The uploaded Excel file should contain exactly three columns: BITS ID, Course, and Total Marks.

Total Marks should be entered as whole numbers. Fractional values should be rounded to the nearest integer (for example, 80.2 → 81).

Students who did not appear for the trimester-end examination and are to be awarded an NC grade should not be included in the file.

This console is intended for grading only those students who appeared for the examination.
